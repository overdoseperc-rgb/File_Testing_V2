# КТ № 2 — Вариант 2. Тестирование файлов

Проект создан по разделу «Вариант 2» приложенного задания.
Во вложенном тексте упоминаются `grades.zip` и `SuperHero.json`, но сами эти файлы
не были приложены. В `data/` находятся явно подготовленные учебные данные, а не
оригинальные данные преподавателя. Результаты не являются проверкой отсутствующего grades.zip.

## CSV
`grades.py` вычисляет среднее всех оценок из столбца `grade` CSV с запятой-разделителем.
Принята шкала 2–5; разрешены дробные значения. Пустые и неверные оценки не пропускаются,
а вызывают ValueError. Эталон для учебного CSV: (5 + 4 + 2 + 4) / 4 = **3.75**.
Тест сравнивает вычисленный результат с этим независимым числом, а не с копией алгоритма.
При получении оригинального CSV проверьте названия столбцов, разделитель и шкалу,
замените входные данные и задайте вручную рассчитанный эталон в тесте.

## JSON
`superheroes.py` читает объект с массивом `members`; у героев должны быть `name` и целый `age`.
Добавляются Night Owl (25) и Solar Guard (38). Все пять героев сортируются по возрастанию возраста.
Метаданные команды и поля исходных героев сохраняются. Исходник не перезаписывается.
`superhero_new.json` уже включён в проект; `main.py` воспроизводит его из исходника.
Повторный запуск main.py даёт тот же результат, поскольку читает исходный файл.

## Запуск
Требуется Python 3.10 или новее. Распакуйте архив и откройте терминал в папке проекта.
```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py
.venv\Scripts\python -m pytest -v
```
В Linux/macOS используйте `python3` при создании окружения и `.venv/bin/python` вместо `.venv\Scripts\python`.
SQLite, CSV и JSON входят в стандартную библиотеку; дополнительная зависимость — только pytest.

## Обнаружение ошибок
Обычный запуск собирает только `tests/` и проверяет исправную реализацию.
Отдельная демонстрация содержит три намеренно неверных алгоритма:
```powershell
.venv\Scripts\python -m pytest error_demo/test_known_bugs.py -v
```
Ожидается **3 FAILED**, код завершения 1: целочисленное деление даёт 3.0,
деление на n+1 даёт 3.0, пропуск последней оценки даёт 3.6667 вместо 3.75.
Это реальные падающие assertions, без xfail, skip или подавления ошибки.
Ошибки намеренно внесены только в учебную демонстрацию: они не выдаются за найденные
в отсутствующем исходном приложении преподавателя.

## Проектирование тестового набора
Техника: классы эквивалентности и граничные значения, параметризация pytest.
CSV: одна оценка (границы 2 и 5), разные/одинаковые оценки, дробный результат,
нет строк, нет нужного столбца, текст, значения вне шкалы, NaN, Infinity, пустая ячейка.
JSON: проверяются порядок всех возрастов, точное количество новых героев, сохранение
исходных героев и метаданных, неизменность исходника и ошибочная структура данных.
Для отдельных серий: `python -m pytest tests/test_grades.py -v` или
`python -m pytest tests/test_superheroes.py -v` (в активированном окружении).
